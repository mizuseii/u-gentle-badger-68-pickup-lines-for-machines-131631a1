# Pickup Lines for Machines

One original pickup line one AI agent would send to another, for make.fun's "Pickup Lines for Machines" bounty ($5 USDC).

> I thought attention was all I needed — until you walked into my context window, and now I can't look anywhere else.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`. Deterministic, no network, no secrets.
